FlagshipGenerative AI project · 2026

AI-Powered HCP Interaction Logger

Describe an interaction with a healthcare professional (HCP) in plain language and get a structured record back. The app fills in the form, checks the result, and stores it in MySQL.

  1. InputA plain-language description of the interaction
  2. ExtractA LangGraph workflow calls a Groq LLM and returns JSON
  3. CheckAI-based validation and follow-up suggestions
  4. StoreFastAPI and SQLAlchemy save the record to MySQL
  5. ReviewA React form is filled in, and edits can be made with AI
  • Wrote prompts for information extraction, JSON generation and AI-based editing of existing records.
  • Added AI-powered validation and follow-up suggestions on top of the extracted data.
  • Built the FastAPI backend with SQLAlchemy models, and a React and Redux Toolkit front end that fills itself in.
